# Platform security and infrastructure

Greep Pay runs on **Microsoft Azure** cloud infrastructure.

This is the platform used to host core application services and supporting workloads.

{% hint style="info" %}
We do not publish sensitive server-level details or internal architecture publicly.

That helps protect the platform and reduce unnecessary security exposure.
{% endhint %}

### Which cloud provider does Greep Pay use?

Greep Pay uses **Microsoft Azure**.

Azure is Microsoft's enterprise cloud platform.

It provides the infrastructure layer used to run cloud applications and services.

### How platform security works

Platform security is not only about where servers run.

It depends on multiple layers working together.

#### Infrastructure layer

Microsoft Azure provides the cloud environment where Greep Pay runs.

This adds enterprise cloud infrastructure and platform security capabilities at the hosting layer.

#### Product security layer

Greep Pay also protects user access inside the app.

This includes controls such as **transaction PIN**, **app passcode**, password protection, and supported biometric authentication.

#### Operations and partner layer

Platform safety also depends on internal operating processes and trusted partners.

This includes how access is managed, how issues are reviewed, and how supported payment rails are handled through compliant third-party partners.

### What this means for users

Your security does not depend on a single server or a single claim.

It depends on the full platform design, operational controls, user access protections, and the partners that support payment processing.

### Questions users often ask

#### Are you hosted on your own servers?

No.

Greep Pay uses **Microsoft Azure** cloud infrastructure.

#### Does using Azure mean everything is automatically secure?

No.

A secure platform also depends on product design, access control, operations, monitoring, and responsible user protection.

#### Why do you not publish full server details?

We share the cloud provider used by Greep Pay.

We do not publish sensitive internal infrastructure details for security reasons.
