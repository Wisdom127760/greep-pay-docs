# How to Create a Savings Pot

Create a **Savings Pot** in Greep Pay to save for a goal, lock funds for a set period, or save flexibly.

Use this flow to choose a pot type, add your savings details, and fund the pot from your wallet balance.

{% include "../../../.gitbook/includes/savings-related-terms.md" %}

{% stepper %}
{% step %}
### Open Savings

From the home screen, tap **Savings**.
{% endstep %}

{% step %}
### Create a new pot

Tap **Create Pot**.

Choose your pot type:

* **Flex** — save freely and withdraw anytime
* **Goal** — save toward a target amount
* **Vault** — lock funds for a set period
{% endstep %}

{% step %}
### Add your pot details

* Enter a **Title** for your pot, such as **Rent**, **Phone**, or **Emergency**
* Set a **Goal Amount** if your selected pot type uses a target
* Set the **Vault** duration only if you choose **Vault**
* Turn on **Lock Pot** if you want to limit withdrawals until your goal is reached
{% endstep %}

{% step %}
### Set auto-save options

If you want, turn on automatic saving:

* **Percentage of Payment** — save a percentage of each payment automatically
* **Round-Up Payments** — round up each spend and save the difference
{% endstep %}

{% step %}
### Fund your pot

Tap **Fund Pot**.

Enter the amount you want to save.

Select your **Greep Pay wallet balance** as the funding source.

Confirm the transfer.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Rates, interest, and availability can vary by pot type and current product terms.

Check the app before you create or fund a pot.
{% endhint %}
