# P2P Exchangers (Merchant App)

Use the **GreepPay Merchant App** if you want to operate as a P2P exchanger.

This is a separate app for agents who buy and sell stablecoins for local currency.

### What is the GreepPay Merchant App?

The GreepPay Merchant App is built for **P2P exchangers**, also called **agents**.

Use it to create offers, manage availability, and complete P2P orders.

{% hint style="info" %}
As a P2P agent, you can:

* buy and sell **USDT** or **USDC** for local currency
* earn a spread on each transaction
* set your own rates and availability hours
{% endhint %}

### How to become a GreepPay P2P agent

{% stepper %}
{% step %}
### Download the Merchant App

Download the **GreepPay Merchant App** from the **App Store** or **Play Store**.

Use the merchant version of the app, not the customer app.
{% endstep %}

{% step %}
### Register and complete verification

Create your merchant account with your details.

Complete **KYB** business verification before you start trading.
{% endstep %}

{% step %}
### Fund your merchant wallet

Add **USDT** or **USDC** to your **Merchant Wallet**.

Make sure you meet the minimum funding requirement shown in the app.
{% endstep %}

{% step %}
### Create your offers

Set your **buy** and **sell** offers.

Choose your rates, limits, and other terms.
{% endstep %}

{% step %}
### Go online and receive orders

Set your availability status to online.

You can then start receiving P2P orders from users.
{% endstep %}
{% endstepper %}

### How to confirm payment and release escrow

{% stepper %}
{% step %}
### Accept the order

When a user starts a P2P order, you receive a notification in the Merchant App.

Accept the order before the time limit expires.
{% endstep %}

{% step %}
### Wait for user payment

Wait for the user to confirm that they have sent the money.

Do not release funds before you verify payment yourself.
{% endstep %}

{% step %}
### Check your account

Confirm that the payment arrived in your bank account or mobile money account.

Verify the exact amount before you continue.
{% endstep %}

{% step %}
### Release the funds

If payment is confirmed, tap **Release Funds** in the Merchant App.

The user's GreepPay wallet is credited instantly.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Never release funds before payment reaches your account.

Once funds are released, the action cannot be reversed.
{% endhint %}

### What happens next

After you release the funds, the order is marked as completed.

If you also use the customer app, see [How to Fund Your Wallet with P2P](wallet-and-top-up/how-to-fund-your-wallet-with-p2p.md) and [Transfer to Bank Account (P2P)](sending-money/transfer-to-bank-account-p2p.md).
