# Withdraw Money

Withdraw money from Greep Pay with the **Withdraw** flow.

Use this page for fiat withdrawals and saved payout accounts.

For crypto payouts, read [Withdraw to Crypto Wallet](withdraw-to-crypto-wallet.md).

### Video tutorial

Watch how to withdraw from your Greep Pay wallet:

{% embed url="https://www.youtube.com/watch?v=YpLAWyTgPPc" %}

**Related terms:** Withdraw Funds, Bank Transfer, Mobile Money, Crypto Withdrawal, Payout Account, Off-Ramp

{% hint style="info" %}
Available offramp methods depend on your **country**, **currency**, and available providers.

Greep Pay only shows the withdrawal methods supported for your current route.
{% endhint %}

{% hint style="warning" %}
Rates, fees, and minimum or maximum withdrawal limits can change by currency and method.

Always review the final amount before you confirm.
{% endhint %}

### How fiat withdrawal works

{% stepper %}
{% step %}
### Open the withdrawal flow

From the home screen, tap **Withdraw**.

Stay on the **Fiat** tab if you are withdrawing local currency.
{% endstep %}

{% step %}
### Enter the amount and choose the currency

Enter the withdrawal amount.

Select the payout currency if more than one currency is available.
{% endstep %}

{% step %}
### Review the rate and limits

Check the exchange rate, available balance, and any minimum or maximum limits.

Use **Change Rate** if that option is available for your route.
{% endstep %}

{% step %}
### Choose a withdrawal method

Select one of the methods shown for your country and currency.

You may see options such as **Bank Transfer**, **GreepPay Direct**, **Mobile Money**, or other provider-supported payout methods.
{% endstep %}

{% step %}
### Choose or add the payout account

Select an existing bank account or mobile money account.

If needed, tap **Add** to create a new payout account before you continue.
{% endstep %}

{% step %}
### Confirm the withdrawal

Review the amount, recipient details, provider, and fee.

Tap **Withdraw** or **Continue** and enter your **Transaction PIN** if prompted.
{% endstep %}

{% step %}
### Wait for processing

After confirmation, the withdrawal moves to processing.

You can leave the screen and check your status from your transaction history.
{% endstep %}
{% endstepper %}

### Add a withdrawal account

Save payout accounts to make future withdrawals faster.

{% stepper %}
{% step %}
### Open Withdrawal Accounts

Go to **Profile** → **Withdrawal Accounts**.

Tap **Add Account**.
{% endstep %}

{% step %}
### Choose the account type

Select the type of destination you want to save.

Depending on your route, this can include a **bank account**, **mobile money account**, or **crypto wallet**.
{% endstep %}

{% step %}
### Enter the account details

Provide the required payout details, such as the bank, phone number, wallet address, or network.

Add a label if the app supports it.
{% endstep %}

{% step %}
### Review and save

Check the details carefully.

Enter your **Transaction PIN** and save the account.
{% endstep %}
{% endstepper %}

### Manage saved withdrawal accounts

Use **Profile** → **Withdrawal Accounts** to:

* view saved payout accounts
* update account details where editing is supported
* remove accounts you no longer use

### What happens next

After a successful withdrawal, you can view the payout in your transaction history and share the receipt if needed.

If you want to withdraw crypto instead, read [Withdraw to Crypto Wallet](withdraw-to-crypto-wallet.md).
