# How to lock/freeze card

Lock or freeze your Greep Pay virtual card from the **Cards** tab.

Freezing your virtual card helps block new card transactions if you want extra security or do not want the card used for a while.

{% hint style="info" %}
You can unfreeze the card later when you are ready to use it again.

Pending or already approved transactions can still settle after you freeze the card.
{% endhint %}

{% stepper %}
{% step %}
### Open your virtual card

Go to the **Cards** tab in the app.

Select the virtual card you want to lock or freeze.
{% endstep %}

{% step %}
### Tap Lock

On the card screen, tap **Lock**.

This changes your card status and helps stop new payments on the card.
{% endstep %}

{% step %}
### Confirm the card freeze

Review the action if the app asks for confirmation.

Once confirmed, your virtual card is locked or frozen.
{% endstep %}

{% step %}
### Unfreeze the card when needed

Go back to the same card screen when you want to use the card again.

Tap **Lock** again, or use the available toggle, to unfreeze the card.
{% endstep %}
{% endstepper %}

### What happens next

If you need to check your card information, read [How to view card details](how-to-view-card-details.md).

If a transaction still fails after you unfreeze the card, check [Troubleshooting: Card declined](troubleshooting-card-declined.md).
