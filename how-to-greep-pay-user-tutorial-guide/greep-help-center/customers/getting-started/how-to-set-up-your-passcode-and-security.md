# How to Set Up Your Passcode and Security

Protect your Greep Pay account with a secure passcode, biometric login, and strong security settings.

{% columns %}
{% column %}
### Set up your passcode and security

* Go to **Settings**
* Tap **Security**
* Set a **4–6 digit passcode** for app access
* Enable extra security features:
  * **Biometrics** such as **Face ID** or **Fingerprint**
  * **2FA** if it is available

{% hint style="info" %}
Use the same section to change or reset your password.

* Use a **strong, unique password**
* Never share your **OTP**, passcode, or reset link
* Only reset via the **official app**
* Greep Pay will **never ask for your password**

These steps help protect your wallet, login, and transactions.
{% endhint %}

### Why these security settings matter

Your app passcode helps prevent unauthorized access.

Biometric authentication adds a faster and more secure login option.

2FA and password protection help secure sensitive account actions.
