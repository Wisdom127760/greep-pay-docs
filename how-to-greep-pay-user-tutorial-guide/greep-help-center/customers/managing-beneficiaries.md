# Managing Beneficiaries

Manage beneficiaries from the **Send** flow when you pay another Greep Pay user.

Use beneficiaries to save frequent recipients and find them faster next time.

{% hint style="info" %}
You can find recipients by **name**, **tag**, **phone number**, or **email**.

Use **Recent** for recent contacts and **Beneficiary** for saved contacts.
{% endhint %}

{% stepper %}
{% step %}
### Open the send flow

From the home screen, tap **Send**.

Enter the amount you want to send if prompted.
{% endstep %}

{% step %}
### Find the recipient

Use the search bar to look for the recipient.

You can also choose from the **Recent** list.
{% endstep %}

{% step %}
### Save the recipient as a beneficiary

On the recipient list, tap the **star** icon next to the contact you want to save.

Saved contacts appear in the **Beneficiary** tab for faster access.
{% endstep %}

{% step %}
### Choose where to transfer from

Select your funding source, such as **Wallet** or an available card.

Review the available balance before you continue.
{% endstep %}

{% step %}
### Add a note if needed

Enter an optional note or choose a quick tag.

This helps you label the payment.
{% endstep %}

{% step %}
### Complete the payment

Review the recipient, amount, and funding source.

Tap **Make Payment** to continue.
{% endstep %}
{% endstepper %}

### Manage saved beneficiaries

To manage your saved contacts:

* use **Recent** to find people you paid recently
* use **Beneficiary** to open your saved recipient list
* tap the **star** icon again to remove a saved beneficiary

### What happens next

Once you save a beneficiary, you can select them faster during future transfers.

To learn the full transfer flow, read [Transfer to GreepPay Users](sending-money/transfer-to-greeppay-users.md).
