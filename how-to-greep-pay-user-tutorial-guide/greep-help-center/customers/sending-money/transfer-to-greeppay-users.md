# Transfer to GreepPay Users

Send money instantly to another Greep Pay user from the **Send** flow.

Use this option when the recipient already has a Greep Pay account.

### Video tutorial

Watch how to send money instantly to another Greep Pay user:

{% embed url="https://www.youtube.com/watch?v=o3R3FjiVxwE" %}

{% hint style="info" %}
You can send money with a **Greep tag**, **username**, **email**, or a saved beneficiary.

Transfers between Greep Pay users are usually instant.
{% endhint %}

{% stepper %}
{% step %}
### Open the send flow

From the home screen, tap **Send**.

Select **GreepPay Account**.
{% endstep %}

{% step %}
### Choose the recipient

Select a beneficiary from your saved list, or search for the user.

You can search with a Greep tag, username, or email address.
{% endstep %}

{% step %}
### Enter the transfer amount

Type the amount you want to send.

Check your available wallet balance before you continue.
{% endstep %}

{% step %}
### Add a note if needed

Enter an optional note or payment reference.

This helps the recipient understand what the transfer is for.
{% endstep %}

{% step %}
### Review and confirm the transfer

Check the recipient details and amount carefully.

Tap **Continue** and enter your **Transaction PIN**.
{% endstep %}

{% step %}
### Complete the Greep Pay transfer

After confirmation, the transfer is processed instantly.

Both you and the recipient receive a transaction notification.
{% endstep %}
{% endstepper %}

### What happens next

After the transfer succeeds, you can view the transaction details and receipt in your history.

If you want to send money another way, return to [Sending Money](./).
