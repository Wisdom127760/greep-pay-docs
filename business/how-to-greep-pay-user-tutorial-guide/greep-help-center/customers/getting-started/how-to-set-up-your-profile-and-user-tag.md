# How to Set Up Your Profile and User Tag

Set up your Greep Pay profile to personalize your account and create a user tag for faster transfers.

### Edit your profile and create your user tag

{% columns %}
{% column width="66.66666666666666%" %}
#### Steps

* Go to **Profile**
* Tap **Edit Profile**
* Add or update your:
  * Profile picture
  * Full name
* Create a unique **user tag** or **username**
* Save your changes

Use your user tag when you want other Greep Pay users to find you and send money quickly.

You can also share it from the [Receiving Money](../receiving-money.md) flow.
