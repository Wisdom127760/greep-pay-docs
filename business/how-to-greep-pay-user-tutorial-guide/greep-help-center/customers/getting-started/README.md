# Getting Started

Download the Greep Pay app to create your account and start using cross-border payments, wallet top-ups, virtual cards, and transfers.

**Related terms:** Sign Up, Create Account, Download App, KYC, Profile Setup, User Tag, Passcode

### Create your Greep Pay account

{% column width="33.33333333333333%" %}
<figure><img src="../../../.gitbook/assets/mockuuups-free-iphone-17-pro-cosmic-orange-mockup (1).png" alt="" width="188"><figcaption></figcaption></figure>
{% endcolumn %}

{% column width="66.66666666666667%" %}
**Step 1: Tap Create Account**

* On the welcome screen, tap **Create Account**
* Choose **Google**, **Apple**, or **Email**

**Step 2: Enter your details**

* If you use email, enter your email address and password
* Add the requested personal details

{% hint style="warning" %}
Use an email address you can access. Greep Pay sends OTP codes and account updates there.
{% endhint %}

* Accept the Terms of Service and Privacy Policy
* Tap **"Continue"**
{% endcolumn %}
{% endcolumns %}

{% columns %}
{% column width="66.66666666666666%" %}
**Step 3: Create your passcode**

* Create a secure 4-digit passcode
* Use this passcode each time you open the app
* Keep it private and easy for you to remember

**Step 4: Finish setup**

* Choose your preferred display currency
* Select your notification preferences
* Complete any extra verification prompt if shown
{% endcolumn %}

**Step 5: Log in and start using Greep Pay**

* After account creation, log in with your credentials
* Enter your passcode when prompted
* You can now explore your wallet, transfers, and virtual card features

{% hint style="warning" %}
Complete [KYC verification](how-to-complete-kyc-verification.md) to unlock more features, including wallet funding and virtual card access.
{% endhint %}
