# Savings

Greep Pay **Savings** helps you set money aside for planned goals and everyday saving.

Use **Savings Pots** to separate your money by purpose, choose how you want to save, and manage each pot from the **Savings** screen.

{% include "../../../.gitbook/includes/savings-related-terms.md" %}

### What is a Savings Pot?

A **Savings Pot** is a dedicated space in your Greep Pay wallet for saving toward a target or setting money aside.

You can create multiple pots, name them, and track each one separately.

### What you can do with Savings

Use Savings to:

* create a pot for a goal or fixed saving plan
* choose between **Flex**, **Goal**, and **Vault** pot types
* fund your pot from your **Greep Pay wallet balance**
* turn on auto-save features like **Percentage of Payment** and **Round-Up Payments**
* review pot activity and manage available settings

### Savings Pot types

Greep Pay can offer different pot types for different saving styles:

* **Flex** — save with easier access to your funds
* **Goal** — save toward a target amount
* **Vault** — lock funds for a set period

Read [Savings Pot Types Explained](savings-pot-types-explained.md) for a full breakdown.
