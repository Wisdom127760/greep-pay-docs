# Savings Pot Types Explained

Choose the right **Savings Pot** type based on how you want to save in Greep Pay.

{% include "../../../.gitbook/includes/savings-related-terms.md" %}

### Flex Savings Pot

Choose **Flex** if you want a more flexible savings option.

This type is useful when you want to save without locking funds for a fixed period.

### Goal Savings Pot

Choose **Goal** if you want to save toward a specific target amount.

This type is useful for planned expenses such as rent, school fees, travel, or emergency savings.

### Vault Savings Pot

Choose **Vault** if you want to lock funds for a set period.

This type is useful when you want stronger spending control while saving.

### How to choose the right pot

Pick **Flex** if access matters most.

Pick **Goal** if you want to track a savings target.

Pick **Vault** if you want to lock the money for a defined period.
