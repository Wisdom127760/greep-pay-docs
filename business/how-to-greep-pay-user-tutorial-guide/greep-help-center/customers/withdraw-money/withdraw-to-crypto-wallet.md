# Withdraw to Crypto Wallet

Withdraw cryptocurrency from Greep Pay to an external wallet with the **crypto withdrawal** flow.

Use this option when you want to move crypto from your Greep Pay balance to another wallet.

{% hint style="info" %}
You can withdraw supported assets like **BTC**, **ETH**, **USDT**, **USDC**, and **XLM**.
{% endhint %}

{% hint style="warning" %}
Crypto withdrawals are irreversible.

The wallet address and blockchain network must match the recipient wallet exactly.
{% endhint %}

{% stepper %}
{% step %}
### Open the crypto withdrawal flow

From the home screen, tap **Withdraw**.

Select **Crypto Wallet**.
{% endstep %}

{% step %}
### Choose the cryptocurrency

Select the asset you want to withdraw.

Review your available balance before you continue.
{% endstep %}

{% step %}
### Select the network

Choose the network that matches the recipient wallet.

Make sure the recipient can receive that asset on the same network.
{% endstep %}

{% step %}
### Choose the destination wallet

Select a saved withdrawal wallet, or enter the wallet address if prompted.

Check the address carefully before you continue.
{% endstep %}

{% step %}
### Enter the withdrawal amount

Type the amount you want to withdraw.

Review the network fee, total deduction, and amount the wallet will receive.
{% endstep %}

{% step %}
### Review and confirm the withdrawal

Verify the asset, network, wallet address, and amount.

Tap **Continue** and enter your **Transaction PIN**.
{% endstep %}

{% step %}
### Track the blockchain transaction

After confirmation, the transaction is submitted to the blockchain.

You can track the withdrawal status in your transaction history.
{% endstep %}
{% endstepper %}

### What happens next

Blockchain confirmation time depends on the network and current activity.

If you need to save or manage destination wallets, see [Withdrawal Accounts](./).
