# Security and Settings

Manage your Greep Pay security settings from your profile.

Use this section to update your **transaction PIN**, **account password**, and **app passcode**.

For cloud hosting and platform protection, see [Platform security and infrastructure](platform-security-and-infrastructure.md).

**Related terms:** Transaction PIN, Password, Passcode, Biometrics, Security Settings, Account Security, OTP

### Set up your transaction PIN

Use your transaction PIN to approve sensitive actions and payments.

{% hint style="info" %}
If you have not created a transaction PIN yet, Greep Pay prompts you during your first supported transaction.
{% endhint %}

{% stepper %}
{% step %}
### Open the PIN setup

Go to **Profile** → **Security Settings**.

Select **Transaction PIN**.
{% endstep %}

{% step %}
### Create your PIN

Enter a secure PIN when prompted.

Avoid easy combinations such as repeated or sequential numbers.
{% endstep %}

{% step %}
### Confirm your PIN

Enter the same PIN again to confirm it.

Your transaction PIN becomes active after confirmation.
{% endstep %}
{% endstepper %}

### Change your transaction PIN

Use this flow when you want to replace your current transaction PIN.

{% stepper %}
{% step %}
### Open Transaction PIN

Go to **Profile** → **Security Settings**.

Select **Transaction PIN**.
{% endstep %}

{% step %}
### Verify your current PIN

Tap **Change transaction pin**.

Enter your current PIN to continue.
{% endstep %}

{% step %}
### Set a new PIN

Enter your new PIN.

Re-enter it to confirm the change.
{% endstep %}
{% endstepper %}

Enter a strong password with at least 8 characters.

Use a mix of uppercase letters, lowercase letters, numbers, and symbols.

### Security best practices

{% hint style="success" %}
For better account security:

* use unique PINs and passwords for Greep Pay
* enable biometrics when available
* review your transaction history regularly
* report suspicious activity immediately
{% endhint %}

{% hint style="danger" %}
Never do any of these:

* share your PIN, password, passcode, or OTP
* reuse the same credentials across multiple apps
* save your PIN where other people can access it
* trust suspicious links or messages claiming to be from Greep Pay
{% endhint %}

### What happens next

After you update a security setting, use the new credential for future access or approvals.

If you need help with account access or a reset, contact [Customer Support](../customer-support.md).
