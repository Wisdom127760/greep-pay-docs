# Find your API keys

API keys let your website or app talk to Greep Pay.

## Steps

1. Open **Settings**, then **API Keys**.
2. Choose **Test Mode** to try things out, or **Live Mode** for real payments.
3. Each mode has a public key and a secret key. A note under each shows if it is **Never used**.

## Good to know

- **Keep your secret key private.** Don't put it in a website's public code, and never send it to anyone, including our support team.
- If you think a key has been seen by someone else, press **Roll Key** to replace it. Anything using the old key will stop working until you update it.
